# Редактируемые данные

Это единственный источник игровых данных для сайта.

- metadata.yaml описывает исходный слепок целиком;
- professions/*.yaml содержит карточки отдельных профессий;
- site/data создаётся командой python3 generate.py и вручную не редактируется.

## Быстро найти нужную запись

1. Откройте файл профессии.
2. Найдите строку name: с названием умения.
3. Рядом проверьте branch и level.
4. Измените description, specifications или effects.

В некоторых профессиях существуют разные умения с одинаковым названием.
Обязательно сверяйте icon, описание и соседние эффекты.

## Важные правила YAML

- сохраняйте отступы пробелами;
- уровни оставляйте в кавычках, например level: '7';
- текст со знаком двоеточия лучше оставлять в кавычках;
- не используйте табуляцию;
- не меняйте slug: он должен совпадать с именем файла;
- не меняйте source без обновления исходного слепка.

Проверка структуры:

    python3 generate.py --validate-only

Полная инструкция для участников находится в ../CONTRIBUTING.md.
