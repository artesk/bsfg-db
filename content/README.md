# Редактируемые данные

Это единственный источник игровых данных для сайта.

- metadata.yaml описывает исходный слепок целиком;
- professions/*.yaml содержит карточки отдельных профессий;
- specifications/*.yaml содержит таблицы характеристик, в том числе уровни знамён, реликвий, свойств экипировки и наград за военную службу;
- items/equipment.yaml содержит экипировку, рецепты и комплекты. Части комплекта связаны с предметами по клиентскому ID;
- site/data создаётся командой python3 generate.py и вручную не редактируется.

## Быстро найти нужную запись

1. Откройте файл профессии.
2. Найдите строку name: с названием умения.
3. Рядом проверьте branch и level.
4. Измените description, specifications или effects.

В некоторых профессиях существуют разные умения с одинаковым названием.
Обязательно сверяйте icon, описание и соседние эффекты.

## Сверка с клиентом игры

- `profession.class_id` — ID профессии из `ExClassInfo-ru.dat`.
- `skill_id` в записи умения — ID из `SkillName-ru.dat` и `Skillgrp.dat`.
  Для сверки используйте пару `skill_id` и `level` с клиентским подуровнем 0.
  У веток одного умения могут быть разные ID. Записи без уверенного соответствия
  остаются без `skill_id`.
- `branch_group_id` у новых карточек содержит `skill_id` первой ветки. Это
  позволяет показывать три варианта вместе, даже если у них разные названия.
- `source.client_release` указывает выпуск клиента, с которым сверяли карточку.
  `source.data_sha256` и `source.original_url` относятся к сентябрьскому слепку.
  У карточек, собранных из клиента, этих двух полей нет.
- `effects_from_archive: true` помечает эффекты, которые остались в карточке для
  справки после изменения клиентского описания. Сайт показывает их отдельно.
- Когда клиент подтверждает только часть таблицы, в `effects` записываются
  подтверждённые строки, а в `archived_effects` остаются данные слепка.

Русские описания умений берутся из `SkillName-ru.dat`. Иконки сверяются по
`Skillgrp.dat` с использованием пула имён того же релиза. Уровни изучения,
минимальные откаты и подробные таблицы эффектов из сентябрьского слепка
требуют отдельного подтверждения. У новых карточек такие поля оставлены пустыми.

## Важные правила YAML

- сохраняйте отступы пробелами;
- уровни оставляйте в кавычках, например level: '7';
- текст со знаком двоеточия лучше оставлять в кавычках;
- не используйте табуляцию;
- не меняйте slug: он должен совпадать с именем файла;
- не меняйте source без обновления исходного слепка.

Проверка структуры:

    python3 generate.py --validate-only

Полная инструкция для участников находится в ../CONTRIBUTING.md.
